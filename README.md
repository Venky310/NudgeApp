# App Development Course

Course material for the **App Programming** module (M.Sc.).

## Structure

```
lectures/    # slides and notes per week
exercises/   # hands-on tasks
projects/    # project briefs and starter code
```

## Getting started

```bash
git clone https://github.com/amirreza98/App-dev-course.git
cd App-dev-course
```

Requirements: Node.js 20+, Git, and an editor (VS Code recommended).
